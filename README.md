## About

This repository contains my solutions to the projects and exercises completed during the 1337 Piscine.

The Piscine is an intensive coding program designed to develop strong programming foundations through practical projects, peer learning, and rigorous problem-solving challenges.

The curriculum emphasizes writing clean and efficient code while building a solid understanding of the C language and low-level programming concepts.
